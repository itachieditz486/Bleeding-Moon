# Bleeding Moon 0.2.0 - a dark-fantasy pixel-art action game

A 2D side-view action game (HTML5 canvas, plain ES modules, **no dependencies**): cross a moonlit castle approach, then defeat three bosses -
**The Hollow Knight**, **The Abyssal Wraith** and **The Fallen Sovereign**. All art is drawn procedurally in code (no external sprite sheets);
audio is the OGG set from the supplied packs plus a few synthesised sounds (see `CREDITS.md`).

> Status: playable start-to-finish in automated tests (see `TEST_REPORT.md`). **Not** tested by a human player, on a real Android
> device, or in any browser other than headless desktop Chromium. **No APK was built** (the Android SDK could not be downloaded in the build
> environment) - see "Android" below.

## Run it
Any static web server (ES modules do not load from `file://`):
```
python3 -m http.server 8000      # then open http://localhost:8000/
```
Or open **`dist/Bleeding-Moon-single.html`** directly - one self-contained file (2.5 MB, audio embedded), works from `file://` and offline.
Rebuild it with `node tools/bundle.mjs` (no npm install needed).

## Controls
| Action | Keyboard | Touch (landscape) |
|---|---|---|
| Move | Arrow keys / A D | floating stick, left half of the screen |
| Jump (hold = higher) | Space / Z / W / Up | JUMP |
| Attack (3-hit combo) | J / X | ATK |
| Shadow wave (30 energy) | K / C | SHADOW |
| Dash (brief invulnerability) | L / Shift | DASH |
| Pause | Esc / P | II (top right) |
Menus: arrows + Enter/Space, or tap/click. Energy fills by hitting enemies and slowly over time; shrines restore health and energy and set a checkpoint.
Inputs are buffered for 0.14 s, so a press made slightly early (during recovery, a hop, a stun) is not lost.

**Pause menu:** RESUME, RESTART CHECKPOINT, SETTINGS, CONTROLS, **MAIN MENU** (saves your progress first, stops boss music/wind, returns to the title where Continue / New Game / Settings / Controls work again).
**Settings:** master/music/ambience/SFX volume, mute; *Touch and display*: touch controls auto/on/off, control opacity, button size, particles auto/low/high, screen shake, FPS counter.

## Game structure
Moonlit Approach (2 800 px, ghouls + wisps, shrine) -> Hall of the Hollow Knight (boss) -> The Descent (shrine) -> Abyssal Chamber (boss) -> Sovereign's Throne (boss, 3 phases).
Each boss has 3+ telegraphed attacks (minimum 0.45 s warning, enforced in code), a health bar with phase ticks, stagger/hit reactions, phase transitions and a defeat sequence.
Auto-checkpoint at the start of every stage, shrines mid-level, save on boss defeat. Dying reloads the last checkpoint with full health.
Finishing the game shows a victory screen (time + deaths) and **clears the save**; Play Again starts fresh.

## Menus / saves
New Game (asks to overwrite an existing save), Continue (only enabled for a valid save - corrupt/tampered saves are rejected), Settings (master/music/ambience/SFX volume,
mute, touch controls auto/on/off, particles auto/low/high, screen shake, FPS), Controls, Pause. Saves use `localStorage` (keys `bleedingmoon.save.v1`, `bleedingmoon.settings.v1`, `dfg.audio.v1`).

## Android
* **APK via GitHub Actions (no Android Studio):** follow `ANDROID_BUILD_GUIDE.md`. The workflow `.github/workflows/android-apk.yml` builds a debug APK with Capacitor 6 and uploads it as an artifact. **It has not been run yet** (the environment I built this in could not reach GitHub, npm or the Android SDK servers) - treat the first run as a test.
* **Install as a PWA instead:** host the folder over HTTPS, open it in Chrome on Android, "Add to Home screen"; the service worker makes it work offline.
* Never tested on a real Android device.
